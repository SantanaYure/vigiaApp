# Relatório do Desafio 5

Esta pasta contém o relatório final do VigiaApp em DOCX e os documentos usados como referência para sua redação e formatação.

## Arquivos

- `InsurMinds_Desafio5_Relatorio_VigiaApp.docx` — relatório final para entrega.
- `referencias/InsurMinds_Desafio5_Relatorio.pdf` — modelo visual fornecido.
- `referencias/Desafios.pdf` — enunciado dos desafios.
- `referencias/Etapa 1 - Levantamento de riscos climaticos.docx` — levantamento de riscos climáticos usado na solução.

O relatório descreve a implementação disponível na branch `main`, incluindo arquitetura, agentes, fluxo operacional, regras de elegibilidade, geração com Gemini, fallback Groq, exemplos de mensagens e validação em duas rodadas de testes.
